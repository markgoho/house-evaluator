# Extension Icons

## Quick Setup

1. Open `icon-generator.html` in your browser
2. Click "Download" under each icon size (16x16, 48x48, 128x128)
3. Save the files in this directory with the correct names:
   - `icon16.png`
   - `icon48.png`
   - `icon128.png`

## Alternative Options

If you want higher quality icons:

1. **Use Figma/Canva**: Design custom icons with your preferred tool
2. **Use AI Image Generators**: Create professional icons with tools like DALL-E or Midjourney
3. **Icon Libraries**: Download free icons from sites like:
   - [Flaticon](https://www.flaticon.com) (search "house")
   - [Iconfinder](https://www.iconfinder.com) (search "real estate")
   - [Icons8](https://icons8.com) (search "home")

## Icon Requirements

- **Format**: PNG
- **Sizes**: 16x16, 48x48, 128x128 pixels
- **Background**: Can be transparent or solid color
- **Style**: Simple, recognizable house/home symbol
